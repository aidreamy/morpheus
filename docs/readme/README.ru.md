Morpheus представляет собой универсальный coding agent для терминала. Он включает инструменты разработки ПО и *computer tools*, позволяющие взаимодействовать с графическими приложениями.

## Почему Morpheus?

Morpheus не призван заменить устоявшиеся coding agents. Он создан, чтобы работать рядом с ними как слой оркестрации. Вот почему он может вам пригодиться:

- **Мультиагентная работа**: запускайте разные передовые агенты (Claude, Gemini, Codex, Cline и др.) в одном TUI, создавая общее рабочее пространство, где они могут общаться через единый интерфейс.
- **Удобно для экспериментов**: идеально для разработчиков, которые любят пробовать разных агентов и объединять их сильные стороны, а не привязываться к одной экосистеме.
- **Режим менеджера**: продолжайте использовать свои существующие harness'ы агентов, добавляя поверх оркестрацию; особенно удобно при работе над несколькими небольшими задачами одновременно.
- **Нативный TUI-опыт**: провайдеры, модели и режимы работы настраиваются прямо в интерфейсе при минимальной ручной настройке.
- **Модульная архитектура**: независимые переиспользуемые крейты для инструментов разработки, компонентов TUI, SDK и recall памяти.

## Чем отличается от других TUI-оркестраторов

| Возможность                                   | Morpheus                                                                                                                              | Другие TUI-оркестраторы                                                  |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Разделённые панели для нескольких агентов** | Запускайте несколько внешних агентов одновременно в разделённых панелях, у каждого своя сессия, модель и опциональный git worktree    | Обычно ориентированы на одного агента или требуют переключения контекста |
| **Computer tools через accessibility tree**   | Читает графические интерфейсы и работает с ними через структурированное представление, прибегая к скриншотам только при необходимости | Обычно полагаются на скриншоты или вовсе не умеют работать с GUI         |
| **TUI на Rust**                               | Написана с нуля с использованием Ratatui, вдохновлена UX OpenCode                                                                     | Часто веб-терминалы или менее оптимизированные интерфейсы                |
| **Настройка внутри приложения**               | Провайдеры, модели и режимы настраиваются прямо в TUI                                                                                 | Часто требуют внешних файлов конфигурации или флагов CLI                 |
| **Модульные крейты**                          | Инструменты разработки, TUI-виджеты, SDK и recall памяти как независимые переиспользуемые библиотеки                                  | Монолитная архитектура с жёстко связанными компонентами                  |
| **Общее рабочее пространство**                | Несколько агентов сотрудничают через единый интерфейс с координированной раздачей задач                                               | Агенты обычно работают изолированно                                      |

## Основные возможности

- **Мультиагентный режим (`/agents`)**: запускайте внешних агентов (Gemini, Claude, Codex, Cline, …) вместе с основным агентом в разделённых панелях, все доступны из одного промпта. У каждого агента своя сессия, модель и опциональный git worktree, а основной агент координирует их, раздаёт задачи и собирает отчёты как одна команда.
- **Computer tools через accessibility tree**: агент читает графические интерфейсы и работает с ними через компактное структурированное представление, а к скриншотам прибегает только как к запасному варианту. Меньше обработанных изображений, меньше расход токенов.
- **TUI, написанная с нуля на Rust** (Ratatui), вдохновлённая UX OpenCode. Настройка провайдеров, моделей и режимов работы выполняется прямо в интерфейсе, почти без ручной конфигурации.
- **Независимые крейты**: инструменты разработки вынесены в крейты, не зависящие от приложения, и могут использоваться как библиотеки за пределами Morpheus.

## Установка

Протестировано на Linux и Windows. macOS пока не тестировалась; если что-то не сработает, [создайте issue](https://github.com/aidreamy/morpheus/issues) с максимально подробным описанием.

**Linux и macOS** (также работает в Windows через Git Bash / WSL):

```sh
curl -fsSL https://raw.githubusercontent.com/aidreamy/morpheus/main/download.sh | bash
```

**Windows (PowerShell):**

```powershell
irm https://raw.githubusercontent.com/aidreamy/morpheus/main/download.ps1 | iex
```

> Примечание: команда `curl | bash` **не** работает в PowerShell или CMD, потому что в Windows нет нативного `bash`. Используйте скрипт PowerShell выше; Git Bash и WSL тоже подходят.

Необязательные переменные: `MORPHEUS_BIN_DIR` (каталог установки), `MORPHEUS_VERSION` (конкретная версия) и `MORPHEUS_VARIANT` (`slim`, по умолчанию, `slim-embed`, с локальным RAG через fastembed, или `slim-speak`, полная голосовая сборка). Сборки `slim-embed` сейчас публикуются только для Linux x64 и Windows x64; для macOS доступны `slim` и `slim-speak`. В PowerShell задайте их как `$env:MORPHEUS_VERSION = "v0.1.0"` перед запуском команды.

### Голосовой вывод

`slim-speak` — это полная голосовая сборка: локальная речь через Kokoro с включённым фронтендом `speak-phonemize`, поэтому работают португальский (Бразилия) и другие языки без встроенного лексикона, а не только английский и китайский.

```sh
export MORPHEUS_VARIANT=slim-speak
curl -fsSL https://raw.githubusercontent.com/aidreamy/morpheus/main/download.sh | bash
```

Архив включает дополнительный бинарник `morpheus-ttsd`, который приложение запускает как соседний процесс; держите его в том же каталоге, что и `morpheus`. В Linux для воспроизведения нужен один из `paplay`, `pw-play`, `aplay`, `play` или `ffplay`; в macOS используется встроенный `afplay`.

Модель речи не встроена: скачайте пакет Kokoro из [релизов моделей sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models) и распакуйте в `~/.cache/morpheus/models/` (или укажите на распакованный каталог через `MORPHEUS_KOKORO_MODEL_DIR`) — v1.1 для голосов по умолчанию, v1.0 для бразильского португальского голоса.

> **Windows:** голосовой вывод пока не поддерживается. Голосовой демон общается через Unix domain socket и использует Unix process API, поэтому `slim-speak` публикуется только для Linux x64 и macOS (x64 и arm64). В Windows доступны `slim` и `slim-embed`.

После установки запустите `morpheus` в терминале. Если каталог установки отсутствует в вашем `PATH`, скрипт сам выведет команду для его добавления. Если возникнут сложности с установкой, создайте issue, и мы будем рады помочь.

- **Движок решений Laya/ONNX**: необязательная feature `onnx`, предоставляемая crate `morpheus-onnx`; см. [руководство crate](../onnx/onnx.md).
